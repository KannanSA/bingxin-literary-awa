## ⚡ Quick Start (3 Steps)

### Step 1: Create a GitHub Repository

Go to [github.com/new](https://github.com/new) and create a new repository:
- Name: `bingxin-literary-conference` (or your preferred name)
- Visibility: Public or Private
- **Important**: Do NOT initialize with README, .gitignore, or license

### Step 2: Run These Commands

Replace `YOUR_USERNAME` and `YOUR_REPO_NAME`:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git add .
git commit -m "Initial commit: Bingxin Literary Conference website"
git push -u origin main
```

### Step 3: Verify on GitHub

Visit your repository URL to see your code live on GitHub!

## 🔐 Authentication Notes

If GitHub asks for credentials:
- **Username**: Your GitHub username
- **Password**: Use a Personal Access Token (PAT), NOT your password

To create a PAT:
1. GitHub Settings → Developer settings → Personal access tokens
2. Generate new token (classic)
3. Select `repo` scope
4. Copy and use as password
