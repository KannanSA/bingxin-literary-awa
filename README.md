# 🖋️ Bingxin Literary Pen Conference Website

A prestigious showcase website for the **International Bingxin Literary Pen Conference**, featuring Nobel Laureates and celebrating Chinese literary excellence in Singapore.

## 🎯 About

This is the official website for the 3rd International Bingxin Literary Pen Conference, taking place **January 15-20, 2026** in Singapore. The conference honors literary excellence with the presence of two Nobel Prize laureates and celebrates the legacy of renowned Chinese writer Bingxin.

## ✨ Features

- **Elegant Design** - Refined aesthetic inspired by traditional Chinese culture with modern sophistication
- **Nobel Laureate Showcase** - Highlighting distinguished guests including Abdulrazak Gurnah and Wole Soyinka
- **Awards Information** - Details on four major literary awards being presented
- **Event Schedule** - Comprehensive listing of conference activities and venues
- **WeChat Integration** - Easy contact and registration via WeChat with click-to-copy functionality
- **Responsive Layout** - Optimized for all devices from mobile to desktop

## 🛠️ Tech Stack

- **React 19** with TypeScript
- **Vite** for fast development and building
- **Tailwind CSS 4** for styling
- **shadcn/ui** component library
- **Framer Motion** for animations
- **Phosphor Icons** for iconography

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open your browser to the local development server (typically `http://localhost:5173`)

### Build

```bash
npm run build
```

- **Typography**: Playfair Display for headers, Inter for body text
